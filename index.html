Cloud sync

To sync your plan between computer and phone, connect a free Supabase project. Use the same project and account on both devices. Your pace settings, completed workouts, logs and edits will sync.

One-time Supabase setup instructions

Create a free project at supabase.com, then open SQL Editor and run:

create table if not exists public.app_state (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.app_state enable row level security;
create policy "Users manage their own training state"
on public.app_state for all to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

Copy the project URL and publishable/anon key from Project Settings → API. Enter them here and use the same email/password on your computer and phone. Sign-up confirmation may need to be completed from your email before signing in.
