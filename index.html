Cloud sync

To sync your plan between computer and phone, connect a free Supabase project. Use the same project and account on both devices. Your pace settings, completed workouts, logs and edits will sync.

One-time Supabase setup instructions

Create a free project at supabase.com, then run the SQL schema from the repository's README.md in the Supabase SQL Editor. Copy the project URL and publishable/anon key from Project Settings → API. Use the same project and account on your computer and phone.
